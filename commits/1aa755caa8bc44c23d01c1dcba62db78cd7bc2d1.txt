feat(input): declarative JSON action map with deadzones (#50)
Add IActionMap/ActionMap: named actions read as axes (float) or held
states (bool) from the polled IInputService, with bindings declared in
JSON. Per-binding deadzone, scale/negation and inversion are supported;
deadzone remaps normalized stick/trigger readings and only cuts
unbounded mouse movement below the threshold.

ActionMapLoader parses the file named by engine.json's Input.ActionsFile
through ResourceLocator into an immutable ActionMapDefinition, validating
every source/key/axis/deadzone. A missing or malformed file logs a
warning and falls back to an empty map. Two schemes ship (default and
alternate), so swapping controls is a file/config change, not a code
change.

Add ADR input-action-map and CONTEXT glossary entry. Covered by 79 new
tests: deadzone boundaries, combined key+stick bindings, inversion and
negation, mouse axes, the capture gate, unknown actions and scheme swap.
