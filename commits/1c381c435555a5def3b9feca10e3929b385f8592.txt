refactor: address PR #34 review — camera component names + material-owned diffuse mapping
- OrbitCamera component name is now "OrbitCamera" (was "Camera"), so the
  runtime and editor cameras can coexist in one scene; both accept an
  optional name parameter.
- DefaultCameraRegistry (and the editor fake) reject registering a camera
  whose name is already taken (InvalidOperationException).
- EditorUI/DefaultScene look up cameras by the ICamera type instead of a
  hardcoded "Camera" component key.
- DiffuseMaterialStrategy/PbrMaterialStrategy/MaterialStrategyResolver and
  the renderer-side strategy plumbing are removed: Material.DiffuseTexture
  and Material.DiffuseColor are virtual, and PbrMaterial overrides them to
  resolve the engine's single diffuse slot from its glTF base color inputs.
  Renderers go back to plain property reads.
- ADRs updated to the post-review decisions; tests adjusted + new cases
  for duplicate-name rejection and PBR diffuse resolution (131 passing).
