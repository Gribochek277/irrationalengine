refactor: SOLID split of VulkanResourceUploader — SRP, OCP, ISP, DIP (4 phases)
Phase 1 — SRP: Split VulkanResourceUploader (44 methods) into two classes:
  VulkanResourceUploader  — buffers, staging, single-time commands
  VulkanTexturePipeline   — images, textures, views, samplers

Phase 2 — OCP: Un-harden creation methods with optional parameters:
  CreateImage(imageType, arrayLayers), UploadTexture(format, generateMips),
  CreateSampler(magFilter, minFilter, anisotropy, compare, ...)
  All defaults match previous behavior — zero breakage.

Phase 3 — Disposal: Route all buffer cleanup through DisposeBuffer()
  instead of raw vk.DestroyBuffer scattered in OnUnload.

Phase 4 — DIP: Introduce IVulkanDeviceContext interface.
  VulkanDevice implements it explicitly. VulkanResourceUploader,
  VulkanTexturePipeline, VulkanCommandUtil accept the abstraction.

Also:
  AGENTS.md — added SOLID Principles + Code Style Preferences sections
  VulkanBuffer/Image/Texture — added to repo (were untracked)
  VulkanRenderer, VulkanImGuiRenderer — wired both classes
