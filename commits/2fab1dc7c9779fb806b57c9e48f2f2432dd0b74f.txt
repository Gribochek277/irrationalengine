feat(engine): polled InputService — mouse delta, edges, pointer lock, axes
InputService now polls the attached device source each Update(): acumulates
mouse position/delta history, computes key/mouse button edges, tracks 16
gamepad slots and applies pointer-lock requests on change (unsupported
backends drop the request once with a warning). While SuppressGameInput is
set, all state reads neutral, but raw history still advances so unsuppressing
is jump-free. Axis aggregation (WASD/arrows + left stick -> MoveX/MoveY,
right stick/triggers -> Look/triggers, clamped [-1,1]) is a pure static
resolver.
