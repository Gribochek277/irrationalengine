feat(scripting): compile the player's Scripts folder with Roslyn
Add the scripting foundation: contracts in IeCoreInterfaces.Scripting, the
IeCoreScripting project (Roslyn compiler, collectible load context, source
locator and the lazy assembly provider), the EngineBehaviour base class, the
script folder configuration and the shipped Spin example.

Scripts compile at runtime from a project-level Scripts folder; base types
resolve from the default load context while the user assembly loads into a
collectible context. A missing folder or a failed compile leaves the engine
running with empty script types and diagnostics in LastErrors.
