feat(audio): 3D positional — camera listener, emitter components (#62)
Positional audio: the game camera carries a listener whose pose is derived
from the active camera each frame, and scene objects can carry an emitter
component with an audio-asset field, distance attenuation and panning.

- IeCoreInterfaces: AudioListenerPose/AudioEmitterSettings value types,
  IAudioService.SetListener/PlayAt/UpdateEmitterPosition, IAudioUpdater,
  IAudioEmitterComponent/IAudioListenerComponent.
- IeCoreAudio: pure AudioListenerMath (view matrix -> listener pose) and
  AudioSpatialization (inverse-distance clamped attenuation); the service
  applies attenuation, the backend only pans.
- IeCoreAudioOpenAl: listener pose + positional sources (rolloff 0).
- IeCore: AudioEmitterComponent/AudioListenerComponent and the AudioUpdater
  frame stage, run last by SceneManager; demo camera carries the listener.
- IeCoreEditor: AudioClip object field (path/Load/clear/drag-drop).
- Tests + ADR (docs/adr/audio-3d-positional.md) and CONTEXT glossary entries.
