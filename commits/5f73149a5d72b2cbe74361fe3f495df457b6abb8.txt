feat(audio): Silk.NET OpenAL backend with bundled native library (#43)
OpenAlAudioBackend implements IAudioBackend on Silk.NET.OpenAL 2.18.0
(single bindings vendor): device/context lifecycle, static PCM16 buffer
upload, gain/loop source properties, source-state polling for reaping,
and a graceful unavailable mode (no device -> logged no-op, engine keeps
running). Silk.NET.OpenAL.Soft.Native 1.23.1 bundles the OpenAL Soft
software implementation (soft_oal.dll on Windows, libopenal.so/dylib
elsewhere) — see docs/adr/audio-service-openal.md for the packaging
finding. AddOpenAlAudio() wires one audio layer for both render backends.
