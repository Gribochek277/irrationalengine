feat: scene integration — collider component, kinematic body, per-frame physics updater
IColliderComponent declares a static AABB on a scene object (default =
model-space mesh AABB, same bounds math as frustum culling; explicit
Size/Offset override), wired to the model component by SceneObject.OnLoad
like IAnimationComponent. KinematicBodyComponent owns a capsule body;
IPhysicsUpdater (registered beside the animation stage, run by SceneManager
before rendering) rebuilds the AABB world from enabled colliders each frame,
steps bodies and writes the feet back to the scene-object transform. 7 new
engine tests cover mesh-AABB defaults, explicit boxes, updater landing,
teleport seeding, disabled colliders/bodies and world-transform following.
