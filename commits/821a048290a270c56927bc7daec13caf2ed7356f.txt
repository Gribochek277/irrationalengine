fix: retrieve glTF scene via GltfScene.RootModel in default scene
GltfSceneImporter returns a GltfScene (not a Model) registered under the
file name without extension ("Duck"). Retrieving it as Model returned null and
caused a NullReferenceException on .Meshes. Use Retrieve<GltfScene>("Duck")
and take its RootModel instead.
