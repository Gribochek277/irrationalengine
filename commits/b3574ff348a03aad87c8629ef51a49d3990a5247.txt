feat(content): binary asset cache with mtime invalidation (#45)
Cache parsed glTF/FBX entities beside their source as `<source>.iecache` so a
second load skips parsing and texture decoding.

- IAssetCache contract; BinaryAssetCache owns the file format (magic, schema
  version, source stamp, payload CRC-32) and the stale/corrupt fallback.
- CachedAssetImporter decorates the glTF/FBX importers in AddAssetImporters.
- BinaryAssetWriter/Reader round-trip the entity graph, preserving shared
  textures, skins and geometry by identity; node parents are rebuilt on read.
- Freshness is a pure rule: schema version + source last-write time + length.
- Tests: invalidation, corrupt/truncated cache fallback, serializer round trip,
  decorator cache-hit, real-asset integration and a parse-vs-cache timing check.
