feat: gizmo scale drag — around model anchor, no jitter (#57)
Scale the selected object about its model anchor (center) instead of the
object origin, so the center stays under the cursor during a non-uniform
scale of an offset-mesh model. Displacement along the axis is measured with
the camera-plane projection (same model as translate) rather than the
closest-line projection, which degenerates at the screen edges and when the
axis is viewed end-on.

- GizmoManipulator.ComputeScalePosition: orbit-compensates the object
  position so the world anchor is invariant under a scale change
  (P' = P0 + f(S0) - f(S')).
- GizmoSystem: cache the local anchor offset and start rotation at BeginDrag;
  scale drag now issues SetPosition alongside SetScale.
- Tests: ComputeScalePosition unit tests (anchor fixed, no-op on equal
  scale) + GizmoSystem.Drag_ScaleKeepsModelCenterFixed.

Closes #57. Debug/Release build green (both backends), 109/109 tests pass.
