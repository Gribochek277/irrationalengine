fix(scripting): keep engine assemblies out of the script reference set
A self-contained publish puts the whole app directory into the trusted
platform assembly list, so the compiler was handing scripts IeCore.dll,
IeCoreEditor.dll and every backend as metadata references. Filter the
platform list by engine assembly name (IeCore*, IeUtils) before adding the
three host assemblies, and expose the produced reference paths so tests
assert the layering guarantee against the set itself instead of the test
process closure.
