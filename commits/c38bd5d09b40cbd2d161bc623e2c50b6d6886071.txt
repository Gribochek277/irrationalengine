feat: shader variants by material feature flags (#55)
Shader selection is now driven by material feature flags (diffuse texture,
skinning, alpha mode) through a pure, tested ShaderVariantResolver; the same
material resolves the same variant in GL and VK. A memoized variant provider
per backend compiles each variant at most once per session.

- IeCoreEntities.Shaders: ShaderFeatureFlags + ShaderVariant (LightCount modeled)
- IeCoreInterfaces.Shaders: IShaderVariantProvider; IDefaultShaders variant-driven
- IeCoreRenderPipeline: ShaderVariantResolver + memoizing ShaderVariantProviderBase
- GL/VK: default shaders rewritten per variant; VK pipelines keyed (depth, blend),
  88 B push block with alphaCutoff; descriptor sets keyed (object, slot, variant)
- glTF PbrMaterial alpha mode/cutoff survive import (ModelInstanceFactory)
- Drop IMaterialComponent.ShaderProgram; OpenTK project out of the solution
- Tests: resolver matrix, provider memoization/dispose, PBR alpha propagation,
  renderer ctor null-guards
