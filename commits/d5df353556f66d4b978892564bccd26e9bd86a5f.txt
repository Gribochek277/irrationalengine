feat(serialization): script components survive save, load and duplicate (#37)
Script components are authored content: the scene serializer captures each
script component's type full name and public field values, and restores them
by resolving the type through IScriptAssemblyProvider and deferring the field
values until the script stage binds the component.

- ISceneComponentCodec gains CanCapture/Matches fallbacks so a component whose
  key is an arbitrary script class name is claimed outside the name map.
- ScriptComponentCodec + ScriptFieldValueMapper cover bool, the numeric
  primitives, string, enums by name, Vector2/3/4 and Texture/AudioClip by
  asset name; unknown types, unsupported fields and missing assets warn and
  keep the scene loading.
- ScriptComponent keeps values restored before Bind and applies them before
  Awake, so a load-save cycle and the first frame preserve authored values.
- The script context factory resolves lazily: the scene owns the serializer,
  which now owns the script codec, so an eager factory closes a DI cycle.

Tests: round trip with verbatim field keys, unknown type warn-once, unsupported
field named warning, missing asset, no-scripting serializer, SceneObjectCloner
duplicate, deferred-factory composition guard, pre-bind restore semantics.
